## Pipeline de extracción (las herramientas reales)

| Herramienta | Qué saca | Coste |
|---|---|---|
| **apktool** | resources/, AndroidManifest.xml legible, smali (bytecode) | gratis |
| **jadx-cli** | bytecode → **Java/Kotlin legible** (lo principal) | gratis |
| **aapt2 dump xmltree** | manifest tabular (permisos, activities, services, intents) | gratis (SDK) |
| **androguard** (Python) | API programática para todo lo de arriba + análisis de certificados firma | gratis (pip) |
| **apkleaks** | secrets hardcoded (API keys, URLs, tokens, AWS, Firebase) | gratis |
| **apkid** | detecta packers/obfuscators (ProGuard, DexGuard, packing nativo) | gratis |
| **MobSF** | todo lo anterior + análisis dinámico, en una UI | docker, gratis |
| **frida** | hooks runtime (necesita dispositivo o emulador) | gratis pero requiere device |

## LLM para la fase de razonamiento
