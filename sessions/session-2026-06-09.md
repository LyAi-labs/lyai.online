## Comando base

```bash
wget --mirror \
     --convert-links \
     --adjust-extension \
     --page-requisites \
     --no-parent \
     --restrict-file-names=windows \
     -e robots=off \
     -P ./mirror-elsitio \
     https://elsitio.com/
```

Qué hace cada flag:
- `--mirror` → recursivo + sin límite de profundidad + timestamps (re-descarga solo lo que cambió).
- `--convert-links` → reescribe los enlaces para que funcionen **offline** (navegas el sitio desde tu disco).
- `--adjust-extension` → añade `.html` a páginas que no la tienen (si no, no abren bien).
- `--page-requisites` → baja CSS, JS, imágenes y fuentes que cada página necesita para verse igual.
- `--no-parent` → no sube por encima de la URL que le das (evita bajarse medio internet).
- `-e robots=off` → ignora robots.txt (úsalo solo en sitios propios o con permiso).
- `-P ./mirror-elsitio` → carpeta de destino.

Luego abres `./mirror-elsitio/elsitio.com/index.html` en el navegador y tienes todo navegable.

## Dos avisos importantes

1. **Sitios modernos con JS (React/Vue/Next, SPAs)**: `wget` solo baja el HTML inicial. Si el contenido se genera con JavaScript en el navegador, el mirror sale **vacío o roto**. Para esos casos hay que usar un crawler con navegador headless (Playwright / `crawl4ai`). Dime qué sitio es y lo detecto.
2. **Permiso / blast radius**: descargar un sitio ajeno masivamente puede violar sus términos o disparar rate-limits. Si es tuyo o tienes permiso, perfecto. Si no, conviene `--wait=1 --limit-rate=200k` para ir suave.
