## Cómo se mergean las branches

**Montaje**: el repo principal (`/opt/lyai/app/lyai-ski`) se queda en `main`. Cada lane es un worktree con su rama:
```bash
git worktree add /opt/lyai/app/wt/calc -b lane/calc      # carpeta nueva + rama nueva
# la sesión de esa pestaña trabaja en /opt/lyai/app/wt/calc
```

**Merge de una lane terminada** (rebase + fast-forward, sin nada destructivo):
```bash
# 1) en el worktree de la lane: poner sus commits encima del main más reciente
cd /opt/lyai/app/wt/calc
git fetch origin
git rebase origin/main         # ← si otra lane tocó el MISMO archivo, el conflicto SALE AQUÍ
                               #    (lo resuelves a mano — mejor que un wipe silencioso)
# 2) fast-forward de main + push
cd /opt/lyai/app/lyai-ski
git fetch origin && git merge --ff-only lane/calc && git push origin main
# 3) limpiar la lane
git worktree remove /opt/lyai/app/wt/calc && git branch -d lane/calc
```
