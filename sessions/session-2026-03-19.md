Un "context" es simplemente un perfil de conexión para el cliente Docker. El cliente Docker (en tu WSL2) habla con *daemons* distintos dependiendo del context activo.

**Sourcery** es un refactorizador automático de Python. Analiza tu código en tiempo real y sugiere simplificaciones.

Ejemplo concreto — si en `chat_api.py` tienes:

```python
# Lo que escribiste:
if result is not None:
    return result
else:
    return None

# Sourcery te sugiere inline:
return result  # ← mismo efecto, 3 líneas menos
```

Otros casos que detecta:
- Condiciones negadas innecesariamente (`if not x == y` → `if x != y`)
- Comprehensions que sustituyen bucles for
- Variables intermedias que no aportan nada
- Comparaciones con `True`/`False` redundantes

**Funciona sin configurar** — las sugerencias aparecen como bombillitas amarillas al lado del número de línea. Click → acepta o ignora.

**Limitación real:** tiene un tier gratuito con las refactorizaciones básicas, y un Pro de pago con análisis más profundo (detección de duplicados entre archivos, métricas de complejidad, etc.). Para el volumen de código de Cervell ahora mismo, el tier gratuito es suficiente.

**Mi recomendación: déjala instalada.** No molesta, no ralentiza, y de vez en cuando te ahorra limpiar código a mano. No es crítica pero tiene coste cero.
